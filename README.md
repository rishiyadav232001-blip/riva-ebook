# Riva — Alone, But Not Lost Website

A professional one-page landing page for the 15-page eBook **Alone, But Not Lost** by Riva.

## Files
- `index.html` — website
- `style.css` — design

## Add your payment link
Open `index.html` and find:

`<a class="btn primary large" href="#" ...>`

Replace `#` with your payment/checkout URL.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `style.css`.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.
